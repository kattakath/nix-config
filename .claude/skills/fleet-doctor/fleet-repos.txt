# Fleet manifest for the fleet-doctor skill.
#
# One repo per line, relative to ~/Developer, forge/owner/repo — the SAME
# path shape every repo already lives under (see root CLAUDE.md, global
# ~/.claude/CLAUDE.md "repos live under ~/Developer/<forge>/<owner>/<repo>").
#
# A fleet repo is a COMPOSITION repo. It is NOT "every repo on disk" — a product,
# a scaffold, a published bundle, or a client/personal repo with no Nix/fleet
# relationship is not fleet, however closely related; fleet-doctor is scoped to
# declarative-infra hygiene, not general dev-repo housekeeping. Adding a line needs
# a reason that survives that sentence. An archived repo never goes here — the
# working copy outlives the repo, and a doctor sweeping it reports branches nobody
# can merge. Retirement history lives in git log, not in this file.
#
# Maintenance: when a new fleet repo appears (extracted or greenfield), add one
# line here. Nothing else needs to change — the skill iterates this file.
