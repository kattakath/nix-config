# This is nix-config's own composition (this repo) + the private composition

# Nix/fleet relationship (Infin8, dontsell-ai, silvercreek-ai, deepjobseek,

# hygiene, not general dev-repo housekeeping.

# a doctor sweeping it would be housekeeping someone else's product, which is
# exactly what the scoping rule above excludes.
