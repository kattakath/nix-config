03 — What you can rely on

Incidents become invariants

Idempotency is a reflex, not a retro item — a platform-wide contract across the whole Lambda fleet, advisory-locked migrations, poison-message handling. Every postmortem ends as a CI-enforced guard, so the same failure cannot recur quietly.

Security by construction

Least-privilege IAM, rotation-aware caching, fail-closed gates, no stored keys in CI. Tenant boundaries are chosen so escalation is structurally impossible rather than merely unlikely — and the same discipline shows up in unpaid side projects.

Reuse before rebuild

I build to learn a domain, then delete what an off-the-shelf tool already does — one bespoke 40-file engine came out for a maintained dependency. Less surface area for your team to carry after I hand it over.
